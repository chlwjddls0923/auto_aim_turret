# r4 검출기 비교표 (2026-10-11, GB10)

r4 = COCO yolo11n.pt 에서 새로 학습 (r3_coco 와 같은 레시피: 1280, hsv_h=0.3, batch 32, epochs 100, patience 30, cache=ram).
데이터 = 기존 train 1,423 / val 228 + 새 촬영분 finetune_data(10.08) train 1,068 / val 106 (색칠 외형, 초록·마젠타 동시 배치).
새 데이터 중 64장은 오검출 박스(붉은 물체·도어 스토퍼)를 지운 hard negative (val 쪽 6장은 시간순 분할 유지를 위해 val 에 둠).
best = 74 epoch (val mAP50-95 0.904, mAP50 0.995, P = R = 1.0).

**운용 conf = 0.25** (4번 val 에서 확정). 모든 수치는 NCNN 960x1280 (파이와 같은 형식).

## 판정 규칙 (새 val·새 test, 라벨 없음)
- 모든 장면을 "초록 1 + 마젠타 1"이 정답으로 본다.
- 색: `colorlib.patch_stats(top_frac=0.5)` 고채도 픽셀 a*. 초록 a* < −15, 마젠타 a* > +30, 그 외(또는 고채도 픽셀 < 20개)는 어느 쪽도 아님.
- 장면마다 색별 최고 conf 박스 1개를 타겟, 나머지를 여분으로 센다.
- 여분 유형(위치 기준 추정): x2 > 1270 = 붉은 물체(오른쪽 끝), 높이 ≤ 30 px = 도어 스토퍼, 그 외 = 기타.
- 높이 구간 (검수 라벨 3분위): 작음 < 29.0 px ≤ 중간 < 37.2 px ≤ 큼. 놓친 색은 같은 장면 반대색 박스 높이로 대신.

## 해석할 때 주의
- **test 는 train 과 같은 날(10/08)·같은 장소**에서 찍은 세션의 마지막 10%다. 실제보다 낙관적일 수 있다.
- **위치 정확도(중심 오차)는 새 test 로 재지 않았다** (라벨 없음). 위 중심 오차는 기존 test 98장 기준이다.
- **오검출은 전부 이 장소 특유의 배경**(문 아래 도어 스토퍼, 화면 오른쪽 끝 붉은 물체)이었다.
  r4 에서 줄었지만, **다른 장소에서도 줄어드는지는 이번 test 로는 알 수 없다.**
- 새 val 의 작음 구간은 3~6장, test 는 마젠타 27장뿐이다.
