# 이전 학습 세트의 구성 기록

DGX에만 있던 중간 데이터셋(`ds`, `ds_r2`)은 압축에 넣지 않았고, 어떤 파일이 어느 분할에 있었는지만 남긴다. 이미지는 전부 원본 폴더에 있다.

| 파일 | 내용 |
|---|---|
| `ds_train.txt`, `ds_val.txt` | b1 180장의 세그먼트 단위 분할(train 138 / val 42). `runs/det640`과 해상도 스윕이 쓴 분할 |
| `ds_r2_train.txt`, `ds_r2_val.txt` | **r2를 학습한 세트**(b1 + b2 일부). r2의 의사 라벨로 r2를 평가하면 부풀려지는 이유가 여기에 있다 |

파일 이름은 그 세트 안에서의 이름이다(b1과 b2에 같은 이름의 다른 이미지가 있으므로 `ds_r2`에서 붙인 접두사를 그대로 본다).
